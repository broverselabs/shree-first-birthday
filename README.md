# Shree Kathiriya Birthday Invitation

A mobile-friendly birthday invitation website built as a static HTML page.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` publishes the page whenever a commit is pushed to `main`. After the first successful run, the site will be available at:

`https://broverselabs.github.io/shree-birthday/`

The workflow builds the published site from `index.html` and the `images/` folder.
